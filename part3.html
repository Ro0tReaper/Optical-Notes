What is WDM?

Click to reveal

Wavelength Division Multiplexing. A technology that puts multiple colors of light (wavelengths/λ) onto a single fiber to increase capacity, solving the electronic bottleneck.

The Fiber/Processor Bottleneck

Click to reveal

Fiber capacity grows much faster than electronic switching capacity. To handle a petabit, electronics would need 100,000 ports and 800,000 fiber connections—physically impossible.

OADM / WADM

Click to reveal

Optical/Wavelength Add-Drop Multiplexer. Allows specific wavelengths to be dropped/added at intermediate nodes without converting the entire signal back to electronics.

Passive Star vs. Passive Router

Click to reveal

Star: Broadcasts input to all outputs. Cannot reuse wavelengths. Collisions occur if two inputs use same λ.
Router: Routes specific λ to specific outputs. Allows wavelength reuse.

Wavelength Continuity Constraint

Click to reveal

In OCS, a lightpath must use the exact same wavelength across all links from source to destination. If a link lacks that λ, a wavelength converter is required.

RWA Problem

Click to reveal

Routing and Wavelength Assignment. Given connection requests and limited λ, find the best route and which λ to assign. Strategies: Fixed, Fixed-Alternate, Adaptive routing.

Why is OPS hard to implement?

Click to reveal

Optical Packet Switching requires optical memory (RAM) and optical computing to process headers. Neither exists yet. Contention is resolved via Fiber Delay Lines or Wavelength Converters.

What is OBS?

Click to reveal

Optical Burst Switching. A compromise between OCS and OPS. Multiple packets are grouped into a burst. A control packet is sent first (electronics), the data burst follows optically.

Burst Assembly Methods

Click to reveal

1. Timer-based: Send after T ms.
2. Threshold-based: Send after X packets/bytes.
3. Mixed: Send when timer OR threshold is reached (best performance).

1. Network Basics

Generic Network Architectures

Think of a communication network like a postal system with multiple layers:

  1. Access Networks
    • Where users connect (home, office, local)
    • Like local post offices
  2. Metro Network
    • Connects cities/regions (Like regional sorting facilities)
    • Metro POP (Point of Presence): Intersects routes, switches/grooms traffic to local carriers.
  3. Long Haul Network (Core/Backbone)
    • Connects continents (Like international mail distribution centers)
    • Long Haul Nodes: Switching centers where multiple routes intersect. Switch/groom traffic, add protection/restoration.

3. Why WDM? The Problem

The Fiber/Processor Bottleneck

Real Example (Speed-Mismatch Problem):
To handle a petabit (1 million gigabits) interconnect using current electronic crossbars:
  • Would need 100,000 ports at 10 Gb/s each.
  • Would need 800,000 fiber connections.
  • Physically impossible to build with current electronics!

Solution: Use multiple wavelengths (colors) in one fiber. Instead of one conversation per fiber, pack many conversations (different light colors) into one fiber.

5. Three Generations of WDM Networks

Generation 1: Point-to-Point WDM System

Simple direct connection between two locations. Commercially available since the 1990s. Channel counts of 64 are common; maximum of 160.

Location A ──[Multiple wavelengths in fiber]──> Location B λ₁ → Transmitter 1 λ₂ → Transmitter 2 λ₃ → Transmitter 3 λ₄ → Transmitter 4

Components: TE (Terminal Equipment), TX (Transmitter), Wavelength Multiplexer, Optical Amplifier, Wavelength Demultiplexer.

Generation 2: Wavelength Add/Drop Multiplexers (WADM/OADM)

Add the ability to pick up and drop off specific wavelengths at intermediate nodes. A WADM = demux + switches + mux.

─→ DEMUX (split by color) ─→ SWITCHES (pick/drop) ─→ MUX (combine) ─→ λ₁ ↓ [switch]↓ λ₁ λ₂ ↓ [switch]↓ λ₂ λ₃ ↓ [switch]↓ λ₃ λ₄ ↓ [switch]↓ λ₄ ↓ (can drop here)
Fiber backbone NY → Chicago → Denver → LA.
- λ₁ goes: NY → LA (full path).
- λ₂ goes: NY → Chicago (drops). New λ₂ data added for Chicago → LA.

Limitation: Only works in a line, doesn't provide true "networking" interconnections.

Generation 3: Fiber and Wavelength Cross-Connects

A) Passive Star

Input Fiber 1 ─┐ Input Fiber 2 ─┼─→ [PASSIVE STAR] ─→ Output Fiber 1 Input Fiber 3 ─┼─→ (broadcasts) ─→ Output Fiber 2 Input Fiber 4 ─┘ ─→ Output Fiber 3

Splits input equally to all outputs. Like a radio broadcast.

Problems: NO wavelength reuse. Collisions! If two sources send λ₁ simultaneously, they crash.

B) Passive Router (Wavelength Router)

Routes each wavelength to a SPECIFIC output fiber based on a fixed routing matrix. Allows wavelength reuse. Market names: WGR, AWG, Latin Router.

C) Active Switch (WSXC)

Similar to passive router BUT routing is reconfigurable! Same wavelengths connect to the same space switching fabric, which can be configured on the fly.

Blocking Limitation: Can't send two same-λ signals to the SAME output.
Fix: Use Wavelength Converters to change the color of light.

6. Three Switching Technologies

Technology 1: Wavelength-Routed Networks (OCS - Optical Circuit Switching)

Establish a permanent path (lightpath) before sending data. Like a telephone circuit.

The Wavelength Continuity Constraint
A path might need λ₁ on Link A-B, but only λ₃ is free on Link B-C. Solution: Wavelength Converters!

The RWA Problem (Routing and Wavelength Assignment)

Given requests and limited wavelengths, find the best route and wavelength.

Routing Strategies:

  • Fixed Routing: Always shortest path (Dijkstra's). Simple, fast, blocks often.
  • Fixed-Alternate Routing: Try 3-4 different paths. Better performance.
  • Adaptive Routing: Dynamically choose based on network state. Best, most complex.

Wavelength Assignment Strategies:

  • Random: Assign any available.
  • First-Fit (FF): Take first available wavelength in order. Quick, logically packs wavelengths.
  • Least-Used (LU): Assign wavelength used least across network. Spreads load.
  • Most-Used (MU): Assign wavelength already in use. Fewer conversions needed.

Technology 2: Optical Packet Switching (OPS)

Process packets in the optical domain without OEO conversion. Currently impossible due to lack of Optical RAM and Optical Computing.

The Contention Problem

When two packets try to leave on the same output/wavelength/time. Electronics use RAM; Optics use:

  1. Fiber Delay Lines (FDL): Loop one packet through a long fiber to delay it.
  2. Wavelength Converters: Change one colliding packet to a different wavelength.

Technology 3: Optical Burst Switching (OBS)

The Compromise: Group IP packets into a "burst". Send a control packet ahead (processed electronically). Data burst follows entirely optically.

  1. Ingress Node: Assemble packets, generate control packet, send burst after offset time.
  2. Core Network: Control packet sets up switch. Data burst passes optically.
  3. Egress Node: Disassembles burst back into IP packets.

7. Burst Assembly

1) Timer-Based

Wait T milliseconds, send everything. Predictable delay, variable burst size.

2) Threshold-Based

Send when X packets collected OR Y bytes reached. Variable delay, predictable burst size.

3) Mixed Timer/Threshold

Whichever comes first. Best performance, higher complexity.

Timer = 10ms, Threshold = 100 packets.
Case A: 150 packets in 5ms → Sent at 100 packets.
Case B: 20 packets in 10ms → Sent at 10ms.

8. Burst Scheduling

1) First-Fit (FF)

Search channels in fixed order, assign first eligible. Advantage: Simple, fast. Disadvantage: Sub-optimal gaps.

2) Latest Available Unused Channel (LAUC)

Find the wavelength that becomes free LATEST (closest to burst arrival). Advantage: Fills tight gaps efficiently. Disadvantage: Slower computation.

9. OBS Signaling Protocols

OBS uses One-Way Reservation (source doesn't wait for acknowledgment—saves latency).

1) Just Enough Time (JET)

Reserves bandwidth "just enough" for burst. Specifies exact start/end times. Highly efficient, tight timing.

2) Just In Time (JIT)

Control packet arrives, immediately followed by data. Resources reserved immediately upon control processing.

3) Time Label (TL)

Control packet includes explicit timestamp of when burst will arrive. Nodes set up switch at that time. Flexible, requires accurate clocks.

Summary & Takeaways

Network Comparison

Feature OCS (Wavelength-Routed) OPS OBS
Granularity Wavelength Packet Burst
Switching Circuit-like Packet-like In-between
Optical Processing None Maximum Minimal (control only)

Key Takeaway: WDM solves the electronic bottleneck by using multiple colors of light. OCS is the deployed present (inflexible circuits), OPS is the distant future (optical processing), and OBS is the practical middle-ground (bursts with electronic control, optical data).

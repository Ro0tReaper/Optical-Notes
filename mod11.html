11.1

Hierarchical Networks

Why Scale?

Organizations need networks that can handle:

  • Converged traffic — data, voice, and video on the same network
  • Critical applications — always-on services
  • Diverse business needs — different departments, locations
  • Centralized admin control — manage everything from one place

Campus networks range from a single LAN switch (small) to thousands of connections (large).

Cisco Borderless Network

A network architecture that connects anyone, anywhere, anytime, on any device — securely, reliably, seamlessly.


  • Unifies wired and wireless access on a single framework
  • Built on scalable, resilient hierarchical hardware
  • Key properties: Hierarchical Modular Resilient Flexible

The 3 Layers — Core Concept ⚡

Every layer has a specific, well-defined job. Know all three cold.

🔵 Core Layer
The backbone
High-speed backbone connectivity
Fault isolation
Connects distribution switches
🟣 Distribution Layer
The aggregator
Routing · QoS · Security
Limits Layer 2 broadcast domains
Aggregates wiring closets
Connects access ↔ core
🟢 Access Layer
Where users connect
End-user network access
Connects to distribution layer

Three-Tier Model

  • Has all 3 layers: access, distribution, and core
  • Used by larger organizations with multiple buildings
  • Recommended topology: extended-star from a central building to all others on campus

Two-Tier Model (Collapsed Core)

  • Distribution and core are merged into one layer
  • Used in smaller campuses or single-building sites
  • Also called: collapsed core network design
  • Good when a separate core isn't needed

Role of Switched Networks

  • Networks evolved from flat hub-based networks → switched LANs in a hierarchy
  • Switched LANs provide: flexibility, traffic management, QoS, security
  • Also support: wireless, IP telephony, mobility services
11.2

Scalable Networks

What is Scalability?

A network that can grow without losing availability or reliability. Designers use four core strategies:


1. Redundancy
Eliminate single points of failure with duplicate equipment
2. Multiple Links
EtherChannel for bandwidth aggregation
3. Scalable Routing Protocol
OSPF for large hierarchical networks
4. Wireless Connectivity
WLANs to extend access layer reach

1. Plan for Redundancy

Redundancy = eliminating single points of failure by:

  • Installing duplicate equipment
  • Providing failover services for critical devices
  • Providing redundant paths — alternate physical routes for data

⚠️ Redundant paths in Ethernet = Layer 2 loops. You MUST run Spanning Tree Protocol (STP) to prevent broadcast storms.

2. Reduce Failure Domain Size

A failure domain = the area of the network impacted when something breaks.

  • Hierarchical design terminates failure domains at the distribution layer
  • Each router acts as gateway for a limited number of access layer users
  • Routers or multilayer switches are deployed in pairs → called a building switch block (or departmental switch block)
  • Each switch block acts independently — one failure doesn't bring down the whole network

3. Increase Bandwidth — EtherChannel

Link aggregation combines multiple physical links into one logical link for more bandwidth.


💡 EtherChannel = Cisco's link aggregation technology. Multiple physical ports → one Port Channel interface.

  • Config is done on the Port Channel interface, not each individual port → ensures consistency
  • EtherChannel can load balance traffic across member links

4. Expand the Access Layer — WLANs

Wireless LANs are the go-to method for growing the access layer.

  • Benefits: increased flexibility, reduced costs, adapts to changing needs
  • End devices need a wireless NIC to connect to a wireless router or Access Point (AP)

Key considerations when implementing WLAN:

  • Types of wireless devices connecting
  • Wireless coverage requirements
  • Interference considerations
  • Security considerations

5. Tune Routing Protocols — OSPF

OSPF (Open Shortest Path First) is the standard choice for large enterprise networks.


Type
Link-state routing protocol
Structure
Uses areas to support hierarchical network design
Neighbors
Routers establish and maintain neighbor adjacencies
Database
Routers synchronize their link-state database
Updates
On network change → link-state updates sent to all OSPF routers → new best path calculated

Switch Form Factors

Fixed Configuration

  • Features/ports are set at purchase — cannot be changed
  • Typically 1U (1.75 inches / 44.45 mm) rack height

Modular

  • Chassis accepts field-replaceable line cards
  • Highly expandable — swap cards as needs change

Stackable

  • Multiple switches connected with special cables
  • Operate as one logical switch
  • Great for growing port count without a chassis switch

Non-Stackable

  • Standalone unit — cannot be combined into a stack
📐 Rack thickness is measured in rack units (U). 1U = 1.75 inches = 44.45 mm.

Port Density

Port density = number of ports on a single switch.

  • Fixed switches offer set configurations — e.g., Cisco Catalyst 3850 comes in 12, 24, or 48 port options
  • Modular switches support very high densities — e.g., Cisco Catalyst 9400 supports up to 384 switchport interfaces

Forwarding Rates

How much data (in bits/sec) the switch can process — the switch's throughput capability.

  • Switch product lines are classified by forwarding rates
  • Entry-level switches = lower forwarding rates
  • Enterprise-level switches = higher forwarding rates
  • If rate is too low → can't handle full wire-speed on all ports simultaneously
  • Wire speed = max data rate per port: 100 Mbps / 1 Gbps / 10 Gbps / 100 Gbps
✅ Access layer switches typically don't need full wire speed — they're limited by their uplinks to the distribution layer anyway.

Power over Ethernet (PoE)

PoE lets a switch deliver electrical power over Ethernet cables to connected devices.

  • Supported devices: IP phones, wireless APs, IP cameras
  • Eliminates need for separate power supplies at the device
💰 PoE switches cost more. Only buy PoE when it's actually needed for the installation.

Multilayer Switching

Multilayer switches operate at both Layer 2 and Layer 3.

  • Deployed at core and distribution layers
  • Support routing protocols and forward IP packets at near-Layer-2 speeds
  • Use ASICs (Application-Specific Integrated Circuits) — specialized hardware chips
  • ASICs + dedicated software data structures = forward packets independently of the CPU

11.4

Router Hardware

What Routers Do — Core Functions

  • Route packets using the network portion (prefix) of the destination IP address
  • Select an alternate path if a link goes down
  • Hosts point their default gateway to the local router interface

Additional router functions:

  • Broadcast containment — limits broadcasts to the local network
  • WAN interconnection — connects geographically separated locations
  • Logical grouping — groups users by application or department
  • Security — filters unwanted traffic using Access Control Lists (ACLs)

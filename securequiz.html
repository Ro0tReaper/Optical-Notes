SQL Injection Prevention
Rewrite this vulnerable login code to prevent SQL injection:
$username = $_POST['username']; $password = $_POST['password']; $sql = "SELECT * FROM users WHERE username='$username' AND password='$password'"; $result = mysqli_query($conn, $sql);
✓ Secure Solution
$username = $_POST['username']; $password = $_POST['password']; $stmt = $conn->prepare("SELECT * FROM users WHERE username = ? AND password = ?"); $stmt->bind_param("ss", $username, $password); $stmt->execute(); $result = $stmt->get_result();
Key points: Use prepared statements with parameterized queries. The SQL structure is compiled first, then data is bound - injected SQL in data cannot alter the query structure. Never use string concatenation for SQL.

QUESTION 07 MEDIUM
CSRF Protection
Add CSRF protection to this form processing:

✓ Secure Solution
